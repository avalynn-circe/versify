# Versify

A Claude skill that composes one short poem a day from the vocabulary of a
public-domain poet. The shelf currently holds ten: Emily Dickinson, Edgar
Allan Poe, Walt Whitman, Christina Rossetti, Gerard Manley Hopkins, Lewis
Carroll, Oscar Wilde, Gertrude Stein, John Donne and Robert Frost.

The idea comes from Poet Laureate, a poetry board game by Avalynn Circe:
take everything a poet ever wrote, break it into single words and small
word pairs, and arrange those fragments into something new. The curated
word bank and the constraints do the creative heavy lifting.

Versify is the daily, digital form of that. A script deals fragments at
random (seeded by poet and date, so each day has one draw), Claude arranges
exactly sixteen of them plus glue words into a poem, and a checker proves
nothing was invented.

Everything is Python standard library. There is nothing to install.
Project Gutenberg is touched once per poet, at build time; the morning run
needs nothing but this repository.

## Layout

```
SKILL.md              what Claude follows to produce the daily poem
README.md             this file
data/
  settings.json       draw size, required fragment count, line bounds, rotation
  glue-words.json     free glue (unlimited) and budgeted glue (once each)
  function-words.json grammar words: never in a bank, never half of a pair
library/
  catalog.json        the shelf at a glance, regenerated by build_bank.py
  <poet>/
    meta.json         name, exact source edition(s) and URL(s), color, voice note
    clean.txt         the verse, one line per line, stanzas separated by blanks
    review.json       every candidate fragment and its decision
    bank.json         the built bank: approved fragments only
scripts/
  ingest.py           raw Gutenberg text -> clean verse lines
  propose.py          clean verse -> candidate words and pairs for review
  review.py           local review tool (serves review.html, autosaves)
  review.html         the review page
  build_bank.py       approved review file -> bank.json, then the catalog
  deal.py             random draws, poet rotation, poem checker
sources/raw/          Gutenberg downloads (git-ignored)
tests/                python -m unittest discover -s tests
```

## Adding a poet

No code changes. Four steps, then an evening of review whenever you want
to refine the bank; an unreviewed bank works on the day it is built.

1. **Get the text.** Download the Plain Text UTF-8 Project Gutenberg
   edition to `sources/raw/<id>.txt`. Use Gutenberg editions only.
   Copyright note for Dickinson: the 1890s Todd and Higginson editions on
   Gutenberg are public domain; the Johnson (1955) and Franklin (1998)
   editions are not and must never be used.

2. **Ingest.**

   ```bash
   python scripts/ingest.py sources/raw/1322.txt -o library/whitman/clean.txt --drop '^\S'
   ```

   For prose poems (Stein), add `--keep-caps` so capitalized titles stay
   as text and `--unwrap` so wrapped paragraphs become one line each,
   which lets pairs be found across the wraps.

   This strips the Gutenberg header, footer and license, all-caps title
   lines, roman numeral poem numbers, bracketed notes (single and
   multi-line), lines with no letters, and collapses blank lines so stanza
   breaks survive. Then look at the cleaned file. Every edition is laid
   out differently. Trim what is left with flags:

   - `--start REGEX` drops everything before the first match
   - `--end REGEX` drops everything from the first match onward
   - `--drop REGEX` (repeatable) drops matching lines
   - `--cut START END` (repeatable) drops from a START match up to the
     next END match: prefaces, notes sections, prose between poems
   - `--sub REGEX REPLACEMENT` (repeatable) rewrites lines first, for
     editions that wrap verse in markers
   - `--section REGEX` (repeatable) turns heading lines into section
     markers instead of dropping them; see Sections below

   Only verse should remain. For a poet with several source texts, ingest
   each and concatenate the results into one `clean.txt`.

3. **Propose and review.** Write `library/<poet>/meta.json` (copy an
   existing one: id, name, color, voice note, and `source` or a `sources`
   list with title, edition, URL and Gutenberg id), then:

   ```bash
   python scripts/propose.py whitman
   python scripts/review.py whitman
   ```

   `propose.py` tokenizes the verse (lowercase, accents folded, apostrophes
   and hyphens kept inside words), counts the vocabulary, and proposes
   pairs: adjacent words within a single line, both non-function words,
   seen at least twice, with a pointwise mutual information score above
   the threshold. Nothing longer than two words is ever proposed. Single
   words start as approved, function words as pending, pairs as pending.

   `review.py` opens a local page. Every action saves to
   `library/<poet>/review.json` immediately. Keys: `j`/`k` move, `a`
   approve, `r` reject, `p` back to pending, `s` split a pair (rejects the
   pair, approves both words), `m` merge two words into a pair (the tool
   reports whether they are ever adjacent in the source), `u` undo, `A`/`R`
   approve or reject everything currently shown, `1`/`2` switch between
   pairs and words, `/` search. Suggested order: pairs first (that is
   where the judgment goes), then the pending function words, then skim
   the approved words high-frequency first.

   To put a poet on the shelf without a review pass, approve all pending
   items and reject the function words, which is how the six launch banks
   were built. Set `"reviewed": true` in meta.json once a real pass is done.

   Re-running `propose.py` later is safe: every decision carries over,
   manual merges survive, and candidates that no longer appear are marked
   stale rather than deleted.

4. **Build the bank.**

   ```bash
   python scripts/build_bank.py whitman
   python scripts/deal.py poets
   ```

   `build_bank.py` also regenerates `library/catalog.json`. Add the poet id
   to `rotation` in `data/settings.json` to put them in the daily cycle,
   or leave `rotation` empty to cycle through the whole shelf.

## Launch poet recipes

The exact ingest commands for the six launch poets, so a re-run is a copy
and paste. Raw files are the Plain Text UTF-8 downloads from the URLs in
each `meta.json`, saved as `sources/raw/<id>.txt`.

```bash
# Dickinson (12242): cut each series' front matter, prefaces and the transcriber's note
python scripts/ingest.py sources/raw/12242.txt -o library/dickinson/clean.txt \
  --cut '^POEMS$' '^(I\. LIFE\.|\s+This is my letter to the world)' \
  --section '^(?:[IVX]+\. )?(LIFE|LOVE|NATURE|TIME AND ETERNITY)\.$'

# Poe (10031): window after Ingram's memoir, before the prose poems and essays;
# cut Poe's preface, the four notes sections, the verse drama Politian, and a prose letter
python scripts/ingest.py sources/raw/10031.txt -o library/poe/clean.txt \
  --start '^\s*POEMS OF LATER LIFE\s*$' \
  --end '^\s*PROSE POEMS\.\s*$' \
  --cut '^PREFACE\.$' '^THE RAVEN\.$' \
  --cut '^NOTES\.$' '^\s*(POEMS OF MANHOOD|AN UNPUBLISHED DRAMA|DOUBTFUL POEMS|PROSE POEMS)\.?\s*$' \
  --cut '^\s*AN UNPUBLISHED DRAMA\.?\s*$' '^\s*POEMS OF YOUTH\s*$' \
  --cut '^INTRODUCTION TO POEMS\.--1831\.$' '^SONNET--TO SCIENCE\.$' \
  --section '^\s*(POEMS OF LATER LIFE|POEMS OF MANHOOD|POEMS OF YOUTH|DOUBTFUL POEMS)\.?\s*$'

# Whitman (1322): titles are unindented, verse is indented
python scripts/ingest.py sources/raw/1322.txt -o library/whitman/clean.txt \
  --drop '^\S' --drop '^\s*Walt Whitman\s*$' --section '^BOOK\s+[IVXL]+\.\s+(.+)$'

# Rossetti (19188): start at the first poem, cut one prose note, stop at the transcriber's note
python scripts/ingest.py sources/raw/19188.txt -o library/rossetti/clean.txt \
  --start '^\s+GOBLIN MARKET\.$' --end "^Transcriber's Note:" --cut '^Note\.--' '^$' \
  --section "^\s*(GOBLIN MARKET|DEVOTIONAL PIECES|THE PRINCE'S PROGRESS, ETC|A PAGEANT AND OTHER POEMS)\.$"

# Hopkins (22403): start at the early poems, stop at the editor's notes
python scripts/ingest.py sources/raw/22403.txt -o library/hopkins/clean.txt \
  --start '^_EARLY POEMS_$' --end "^EDITOR'S NOTES$" \
  --cut '^\(Transcriber' '^$' --drop '^\(Variant' \
  --section '^_?(EARLY POEMS|POEMS 1876-1889|UNFINISHED POEMS)_?$'

# Carroll (651, 13, 36308): three sources, concatenated
python scripts/ingest.py sources/raw/651.txt -o /tmp/c651.txt --start '^PHANTASMAGORIA$' --drop '^\S'
python scripts/ingest.py sources/raw/13.txt -o /tmp/c13.txt --start '^Inscribed to a dear Child' \
  --cut '^Contents$' '^PREFACE$' --cut '^PREFACE$' '^\s*Fit the First' --drop '(?i)^\s*fit the \w+\s*$'
python scripts/ingest.py sources/raw/36308.txt -o /tmp/c36308.txt --start '^CONTENTS\.$' \
  --sub '^\[Music:\s*$' '' --sub '^(?!\[)(.*)\]\s*$' '\1'
{ echo '## Phantasmagoria and Other Poems'; echo; cat /tmp/c651.txt; echo; echo '## The Hunting of the Snark'; echo; cat /tmp/c13.txt; echo; echo '## Songs from Alice'; echo; cat /tmp/c36308.txt; } > library/carroll/clean.txt
```

# Wilde (1057): start at Ross's note, cut it and the contents, drop unindented titles, stop at the printer's colophon
python scripts/ingest.py sources/raw/1057.txt -o library/wilde/clean.txt \
  --start '^NOTE$' --cut '^NOTE$' '^\s+TO _drift with every passion' --drop '^\S' \
  --end '^\s*Printed by T\. and A\. CONSTABLE' \
  --section '^(ELEUTHERIA|ROSA MYSTICA|WIND FLOWERS|FLOWERS OF GOLD|IMPRESSIONS DE TH.*|THE FOURTH MOVEMENT|FLOWER OF LOVE|UNCOLLECTED POEMS|THE SPHINX|THE BALLAD OF READING GAOL|RAVENNA)$'

# Stein (15396): prose poems; keep the capitalized titles, unwrap paragraphs, drop the three section headings
python scripts/ingest.py sources/raw/15396.txt -o library/stein/clean.txt \
  --start '^OBJECTS$' --keep-caps --unwrap --section '^(OBJECTS|FOOD|ROOMS)$'

# Donne (48688, Grierson volume 1): Songs and Sonets through the Divine Poems; stop before the elegies
# written about Donne by others; drop italic titles and the textual apparatus the bracket rules miss
python scripts/ingest.py sources/raw/48688.txt -o library/donne/clean.txt \
  --start '^SONGS _AND_ SONETS\.$' --end '^ELEGIES UPON THE AUTHOR$' \
  --drop '^\S' --drop '_16[0-9]{2}' --drop '^\s*[^\[\s]+\]' \
  --section "^(SONGS _AND_ SONETS|EPIGRAMS|ELEGIES|HEROICALL EPISTLE|EPITHALAMIONS|SATYRES|LETTERS TO SEVERALL PERSONAGES|AN ANATOMIE OF THE WORLD|OF THE PROGRESSE OF THE SOULE|EPICEDES AND OBSEQUIES|EPITAPHS|INFINITATI SACRUM|DIVINE POEMS)[.,]?$"

# Frost (3021, 3026, 29345, 58611): four books, concatenated
python scripts/ingest.py sources/raw/3021.txt -o /tmp/f3021.txt --cut '^CONTENTS$' '^Into My Own$' --drop '^\S'
python scripts/ingest.py sources/raw/3026.txt -o /tmp/f3026.txt --cut '^CONTENTS$' '^Mending Wall$' --drop '^\S'
python scripts/ingest.py sources/raw/29345.txt -o /tmp/f29345.txt --start '^\s*CONTENTS\s*$' --end '^Transcriber Notes'
python scripts/ingest.py sources/raw/58611.txt -o /tmp/f58611.txt --start '^\s*I met a lady from the South' --end '^\s*FOOTNOTES\s*$'
{ echo "## A Boy's Will"; echo; cat /tmp/f3021.txt; echo; echo '## North of Boston'; echo; cat /tmp/f3026.txt; echo; echo '## Mountain Interval'; echo; cat /tmp/f29345.txt; echo; echo '## New Hampshire'; echo; cat /tmp/f58611.txt; } > library/frost/clean.txt
```

Then `python scripts/propose.py <poet>` and `python scripts/build_bank.py <poet>`.

Two copyright notes. Stein's Tender Buttons (1914) is public domain; her
Autobiography of Alice B. Toklas (1933) is not until 2029 and is not used.
Frost died in 1963, so his books are public domain in the United States
only; elsewhere they stay in copyright until 2034.

## Dealing

```bash
python scripts/deal.py today                       # today's poet and draw
python scripts/deal.py draw --poet dickinson       # one poet
python scripts/deal.py draw --poet poe --date 2026-11-01 --format text
python scripts/deal.py today --format json --out draw.json
python scripts/deal.py check --draw draw.json --poem poem.txt
```

The seed is derived from the poet and the date, so a day's draw is the same
everywhere. `--seed N` overrides it. A draw never repeats a fragment.
Fragments are weighted by log frequency by default (`--weight uniform` or
`--weight freq` to change), so the words a poet returns to appear often and
the one-off oddities still turn up. Editing a bank changes that day's draw,
because the seed selects positions in the fragment list.

`check` tokenizes the poem with the same tokenizer the bank was built with
and searches for an assignment of every poem word to a dealt fragment or a
glue word, using exactly the required number of distinct fragments. Pairs
must be intact, in order, on one line. One fragment may repeat as a refrain
when both uses end a line. It fails on any word outside the draw, any
budgeted glue word spent twice, the wrong number of fragments, a line count
outside the bounds, or a poem that ends on glue. Claude runs it before
presenting a poem.

## Daily delivery

The skill does not fire on its own. A Routine at
https://claude.ai/code/routines runs it each morning: this repository
attached as the Routine's repository, a daily schedule, push notifications,
and a prompt that says to read SKILL.md and follow it. The repository must
be attached to the Routine; a Routine that only clones it from the prompt
runs the scripts as untrusted code and the automatic permission check can
refuse them.

## Sections

A day's draw comes from one section of the poet's work when the poet has
sections and the section is big enough. Thirty-two words drawn from a
whole career share only the poet; thirty-two drawn from one book share a
world, so the fragments arrive already leaning toward a poem.

`ingest.py --section REGEX` turns heading lines into markers (`## Name`)
in `clean.txt`; a poet built from several texts gets markers written into
the concatenation instead. `propose.py` records which sections each
fragment appears in, the bank carries that, and `deal.py` picks one
section per poet per day (seeded, so the pick is as stable as the draw)
among those with at least `section_min_words` distinct words (400). A
poet with no sections, or none big enough, deals from the whole bank. The
colophon names the section: "Assembled from the words of Walt Whitman
(Drum-Taps), 14 October 2026."

`python scripts/deal.py sections --poet donne` lists a poet's sections.
`--section NAME` on a draw forces one, `--section none` uses the whole
bank, and `"sections": false` in settings turns the feature off.

## Calendar

`data/calendar.json` overrides the rotation on particular days. Each entry
names a poet, a kind (`birthday`, `deathday` or `season`), a date as
`MM-DD` or a `from` and `to` range, and a phrase that the colophon inserts
after the poet's name ("Assembled from the words of Edgar Allan Poe, on the
anniversary of his death, 7 October 2026."). Precedence on a day with
several claims: birthday, then deathday, then season. Set `"deathdays":
false` to ignore every deathday entry. An occasion changes the poet and
the colophon, never the draw itself. `python scripts/deal.py calendar`
lists the year's overrides; `--days 30` shows who is up each day.

## Settings

`data/settings.json`: `draw` fragments dealt (32), `use` fragments the poem
must contain (16), `min_lines` and `max_lines` (4 and 8), `weight`,
`rotation` (poet ids in daily order; empty means the whole shelf) and
`rotation_epoch` (the date on which the first poet in the rotation is up),
and the pair thresholds.

`data/glue-words.json`: `free` words (articles and the smallest
connectives) are unlimited. `once` words (pronouns, not, but) may be spent
once each; list one twice to allow it twice.
